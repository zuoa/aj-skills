# aj-skills

## 安装

交互式选择要安装的技能：

```bash
npx skills add https://github.com/zuoa/aj-skills
```

安装指定技能：

```bash
npx skills add https://github.com/zuoa/aj-skills --skill aj-stock-analysis
```
