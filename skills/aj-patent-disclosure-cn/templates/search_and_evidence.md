# 现有技术检索与证据规则

## 目标

检索的目的不是寻找几个“看起来相似”的摘要，而是建立可复核的证据链：哪些技术特征被何时、由哪一份文献公开，区别特征是否得到技术启示，以及检索仍有哪些盲区。

## 一、检索前提

先记录：

- 拟申请日、优先权日或用户指定的检索截止日；
- 发明的一句话技术构思；
- 独立主题候选及其必要技术特征；
- 同义词、上位词、下位词、缩写、中英文术语；
- 可能的 IPC/CPC 入口（仅作检索线索，使用时核验当前分类版本）。

不要把“最近 10 年”设为唯一范围。新颖性相关现有技术可能更早；时间过滤只用于提高效率，不能替代完整性判断。

## 二、检索顺序

### 1. 概念宽检

分别组合：

- 技术问题 + 处理对象；
- 核心手段 + 关键关系；
- 输入/输出 + 效果指标；
- 核心模块/步骤的同义表达；
- 英文术语、缩写和常见翻译。

避免用整段发明描述直接搜索，因为措辞变化会造成漏检。

### 2. 分类与主体精筛

- 从高相关文献提取 IPC/CPC，再交叉检索关键词；
- 检索主要申请人、发明人、同族和引证/被引证文献；
- 对中国申请核对 CNIPA 公开文本；外国专利核对相应官方数据库或 WIPO/EPO 文本；
- 必要时检索论文、标准、产品手册、开源代码、会议材料等非专利文献。

### 3. 逐项阅读

对高相关文献至少核对：

- 标题、公开号/文献标识、公开日、优先权日；
- 申请人/作者；
- 独立权利要求；
- 说明书中真正公开相关关系的段落和附图；
- 同族中是否存在更早公开文本；
- 文献是否在检索截止日前已向公众公开。

摘要只能用于筛选，不能单独支撑复杂的特征判断。

## 三、检索记录格式

每份文献记录：

| 字段 | 要求 |
|---|---|
| 文献标识 | 公开号、DOI、标准号或稳定标识 |
| 标题 | 与公开文本一致 |
| 公开日/优先权日 | 分开记录，不混用 |
| 申请人/作者 | 与来源一致 |
| 来源链接 | 直接指向公开文本或官方记录 |
| 相关位置 | 权利要求号、段落号、页码或图号 |
| 公开内容 | 客观摘述，不扩大解释 |
| 与本方案关系 | 相同、部分相同、背景相关或仅关键词相似 |
| 核验状态 | 已核验全文/仅核验摘要/待核验 |

无法核验的字段写“待核验”，不得补造。

## 四、新颖性特征对照

对每个独立主题制作单一文献对照表：

| 必要技术特征 | 对比文件 1 | 证据位置 | 结论 |
|---|---|---|---|
| F1 | 明确公开 | 权利要求 1 | 是 |
| F2 | 未见公开 | — | 否 |
| F3 | 仅可能隐含 | 段落 [0032] | 需论证 |

判断纪律：

- 新颖性以一份对比文件是否直接、明确公开全部必要技术特征为核心；
- 不把多份文献拼接后称为“不新颖”；
- 文字相似度不是法律判断；
- “可能隐含”需要说明为何本领域技术人员能直接、无歧义地得出；
- 输出“初步检索未发现”而不是“全球首次”或“绝对新颖”。

## 五、创造性分析

按以下链条写，避免直接给主观分数：

1. 选择最接近现有技术，并说明选择理由；
2. 逐项确定区别特征；
3. 根据区别特征产生的技术效果，重述实际解决的技术问题；
4. 查找现有技术整体是否给出采用该区别特征的技术启示；
5. 评估结合动机、适配难点、相互作用、预料不到的效果和反向教导；
6. 给出“风险高/中/低 + 证据置信度”，并说明检索局限。

AI/算法方案特别检查：

- 仅应用对象或行业场景不同，算法流程和模型参数没有实质变化；
- 相同场景下是否针对数据特性调整特征、结构、层级、损失函数或训练策略；
- 算法特征是否与技术特征功能上相互支持并产生技术效果；
- 申请材料是否充分披露这些调整，而不只是事后论证。

## 六、风险措辞

推荐：

- “在已检索数据库和检索式范围内，尚未发现单一文献同时公开 F1–F5。”
- “文件 X 公开 F1–F3；F4 的差异能否产生非显而易见的技术效果，取决于待补实验。”
- “当前结论置信度为中，原因是未完成非专利文献和英文同义词检索。”

避免：

- “相似度 82%，所以不新颖”；
- “授权概率 90%”；
- “没有任何相关专利”；
- 没有实际检索却列出公开号或申请人；
- 把优先权日误写成公开日；
- 只读摘要便断言文献公开了全部技术关系。
