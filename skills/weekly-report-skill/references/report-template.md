# 报告模板

---

# {周报 / 月报} — {时间范围}

生成时间：{时间}
本期来源文件：{N} 个
规划文件：{规划文件名}
上期总结文件：{上期总结文件名列表}
涉及部门：{部门列表}
跟踪事项：{目标跟踪清单数量} 项

## 一、{本期周期}工作总结

### 1. 摘要

{3-5 句话。只写关键事实：本期跟踪事项数量、达成数量、偏差数量、无记录待补充数量、主要风险。不做评价，不用形容词。}

示例：
本期共跟踪 X 项事项，X 项达成，X 项存在偏差，X 项无记录待补充。{最大偏差项}落后预期，原因为{文档中的原因；无记录则写"原因未说明"}。下期需关注{风险描述}。

### 2. 规划里程碑完成情况及偏差

{按规划文件和上期总结文件中的事项逐条罗列。每条事项使用"事项：进展说明。"格式，不使用表格。未说明进展的事项仍要保留。}

{事项名称}：{状态。实际进展。偏差/原因。来源：{来源文件}。}

{事项名称}：无记录，待人工补充。预期为{预期指标或节点}。来源：规划文件/上期总结文件；本期总结无记录。

状态写法：
- 已完成：用于完成或超额完成。
- 进度偏差：用于部分完成、有实质进展但未达预期。
- 未完成：用于明确未做、暂停、延期。
- 无记录，待人工补充：用于规划文件或上期总结文件中有要求，但本期输入未说明进展。

### 3. 指标

{按指标逐条罗列。每条指标使用"部门/指标：结果说明。"格式。能计算完成率则写完成率；无法计算则写"无法计算"。}

{部门或指标名称}：目标值{目标值；未说明写"未说明"}，本期结果{结果；无记录时写"无记录，待人工补充"}，完成率/差额{完成率或差额；无法计算写"无法计算"}。来源：{规划文件/上期总结文件/本期总结文件}。

### 4. {专题/解决方案名称}

{如规划文件或本期总结中存在专题，例如校园解决方案、展会材料、重点产品方案，按专题单独成节。无专题时可省略本节。}

{专题名称}：{本期进展。输出物。偏差或待补充内容。来源：{来源文件}。}

### 5. 各部门核心交付结果

{按部门逐条罗列。每个部门使用"部门：内容。"格式。必须覆盖规划文件和上期总结文件中出现的部门。}

{部门名称}：{完成事项。计划内但未说明进展的事项直接写"其中，{事项}无记录，待人工补充"。计划外事项可写"另新增{事项}"。存在问题写在同一段末尾或下一段。来源：{来源文件}。}

{部门名称}：无记录，待人工补充。需补充{规划文件或上期总结文件中要求的计划事项、指标结果、风险原因或时间节点}。来源：规划文件/上期总结文件；本期总结无记录。

### 6. 存在的阻碍与风险

{按风险类别纵向罗列。风险来源于本期偏差、部门问题、上期遗留风险、规划文件已识别风险。无进展说明的风险也保留在对应类别下。}

{风险类别}：
{风险事项}：{风险描述。影响。当前处理情况。来源：{来源文件}。}
{风险事项}：无记录，待人工补充。来源：规划文件/上期总结文件；本期总结无记录。

## 二、{下期周期}工作规划

### 1. 核心里程碑

{按规划文件、上期总结文件和本期总结中明确提出的下期计划逐条罗列。}

（1）{里程碑事项}。{预期结果、时间节点、负责部门、依赖项或风险。}
（2）{里程碑事项}。{预期结果、时间节点、负责部门、依赖项或风险。}

### 2. 各部门核心交付计划

{按部门纵向罗列。月份计划可按"4月/5月/6月"或"第X周"继续缩进罗列。}

{部门名称}：
{时间节点}：{计划事项。预期结果。依赖项或风险。}
{时间节点}：{计划事项。预期结果。依赖项或风险。}
其他：{跨期支持事项、协同事项或待补充事项。}

{部门名称}：{计划事项。预期结果。依赖项或风险。}

### 3. 存在的风险

{只写会影响下期规划落地的风险。每条风险说明来源、影响和需关注点。}

{风险事项}：{风险描述。影响{影响范围}。建议关注{关注点}。来源：{来源文件}。}

{逐条列出修改时间早于报告周期的文件；如无写"无"。}

数据缺失说明：
{说明哪些规划事项、上期遗留事项、指标或风险在本期输入中无记录，且已在对应章节标注"无记录，待人工补充"；如无写"无"。}
