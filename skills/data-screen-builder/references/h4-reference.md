# h4：校园能耗驾驶舱参考

来源：[用户提供的页面](http://h4.appcase.cn/)。观察日期：2026-10-12；1920×1080；深色驾驶舱、演示数据。页面显示“青禾 · 校园能耗管理”，包含指标、双回路趋势、能耗结构、楼宇排名、校园示意场景、教室时段矩阵和异常处置。参考图见 [视觉基线](visual-baselines/h4-1920.png)。它是历史迭代中用户提供的参考案例，不宣称为外部通用标准。

## 从成品提取的关系

| 观察 | 在模板中的转译 |
| --- | --- |
| 标题居中，两侧品牌/时钟动作保持清楚的区域，短线与渐弱高光围绕文字 | `TitleFrame` 同时包含文字和光轨，头部三列布局；不使用文字外的巨型底板 |
| 主标题约 35px、600 字重，英文说明约 9px；数字有紧凑字形，单位显著小于数字 | 该案例的模板曾采用 34px 标题、40px 指标数字；字号/字重/字距写入共享 token，具体数值仍按任务与观看距离调整 |
| 青蓝表达数据，青绿作为辅助强调，琥珀用于风险；边框、表面、脚注有层次 | `theme.ts` 定义角色色；风险不能与品牌强调混为一色；降低大面积辉光 |
| 多数面板为细线表面，头/体/脚均有稳定结构；每张图有自己的单位、注释和阅读理由 | `Panel` 的 head/body/foot；绑定增加可选 `caption`，正常状态不机械重复“已更新” |
| 主体是窄侧栏—宽中心—窄侧栏，中心场景下方接矩阵，信息有方向与对应关系 | 场景和热力矩阵居中；趋势/构成/排名在左；异常与明细在右；指标数来自业务问题 |
| 线图轻网格，排名细条且附具体数值，环图有数字中心，矩阵有清晰刻度与色阶 | `ChartView` 配方共用字体和角色色，显式保留图例和坐标轴空间 |
| 建筑有屋顶、窗格、道路与绿化；标签与场景位置紧密相连 | `SceneMap` 在同一 SVG 投影内绘制建筑和交互标签，避免混合坐标造成漂移 |
| 控制和状态从属于内容，详细操作可展开 | 主工具栏保留范围/时间/更新；视觉偏好收进“显示设置”，指标口径在局部浮层里查看 |

其中字号等数值来自公开页面渲染样式；本项目 token 是转译选择。不会复制能源业务的指标口径、告警检测或处置状态；园区示例继续使用独立指标协议与明确标注的示例数据。

## 本次纠正的失败方式

之前模板用加大标题、厚底板、全亮边框和大量光束回应“精致”，又仅检查面板是否在视口内。实际问题还包括标题光轨穿过文本、不同元素分别定位、数据区字号与空白关系松散，以及图例/刻度空间不足。

现在要求完整参考解析、共享 token、同坐标场景标签、内部布局检查和同尺寸截图比较。每个自动通过项只能证明对应几何约束；“视觉达到要求”需要评议证据与用户认可。
