# 运行策略与验收

## 展示与值守

展示模式允许主动选择的轮播和短过渡；值守模式默认减少装饰动效，异常与过期状态常驻。两类模式都应保留时间、筛选、来源和质量提示。告警列表只是已存在告警的展示，不意味着实现检测、确认、派单或通知后端。

模板用一个共享调度器服务多个查询：相同查询共享请求；失败指数退避；停止订阅后取消请求；切换筛选订阅新查询，旧请求只影响旧缓存。暂停停止新请求并取消进行中请求，但保留数据并持续检查新鲜度；恢复立即读取最新状态。

滚动时间窗口更新时，组件可暂留同一指标/维度/筛选/粒度/窗口长度的上一窗口结果，并明确标记“上一时间窗口”。改变区域、指标或窗口长度不复用旧结果，避免把旧范围数据显示为新范围。保留期间仍用实际数据截至时间检查过期。

默认调度不依赖浏览器后台标签的精确定时，也不宣称浏览器能保证实时 SLA。实际刷新频率应匹配生产更新频率和限流。数据量大时优先服务端聚合/降采样，按目标设备比较 Canvas 与 SVG；不以一套固定 FPS 或加载时间声称所有设备达标。

## 自动验证

```bash
npm run validate:framework
npm run validate
npm test
npm run build:demo
VITE_DATA_PROVIDER=http npm run build
python3 <skill-path>/scripts/validate_screen.py <project-directory>
```

验证 schema 和跨配置引用；核心测试覆盖缓存去重、取消、超时、过期、失败保留数据、恢复、HTTP 不回退 mock、非法结果、零与 null、比例与不可加总口径元数据、时间过滤与时区、联动查询改变。新组件有不同数据形状时增加对应绑定校验。

填报测试覆盖保存立即更新多个订阅者、刷新持久化、同长度滚动窗口保留、不同大屏/区域/时间范围隔离、取消迟到响应、暂停时保存、恢复原 provider、跨标签同步、结构变更失效、损坏缓存和存储失败。真实 API 失败不触发自动填报或 mock 回退。

## 浏览器与长期运行

目标尺寸下检查长中文、负值/极值、图例、单位、标签、对比度、地图选中、筛选重置、表格、暂停、减少动效及错误恢复。检查键盘操作与可访问的数据表替代；Canvas 图不能成为唯一的数据入口。

检查正常大屏与显示设置没有填报按钮；快捷键和 `?view=report` 均能打开填写界面，关闭回到大屏；触屏/窄屏可用地址入口。实际填写数字与分组/趋势数据，核对保存、刷新、切换筛选、恢复及来源标记。填报弹窗不随大屏画布缩放或被其裁切，支持键盘、Esc 关闭和未保存修改提示；空框架仍不加载业务数据。

至少覆盖 1280×720、1366×768、1920×1080、2560×1440、3840×2160，以及超宽屏、4:3 和窄屏。检查整幅画布及所有面板在视口内、比例保持一致、不同宽高比居中留边；改变窗口后无需刷新页面即生效。不能仅检查横向滚动。缩放后的沙盘/图表点击、筛选控件和数据详情仍可用；详情采用局部浮层，不能撑大固定画布。实际墙屏必须用其真实观看距离和缩放设置复核。多页面时检查资源释放；持续运行时观察内存、请求次数和数据新鲜度。

根据硬件、组件数量、数据量、刷新要求商定首屏/交互/内存预算和 soak 时长。未做持续运行测试时记录未执行及建议条件，不能把短时浏览器 smoke 写为“长期运行通过”。

额外输出内部几何快照，格式为 `{"viewports":[{"width":1920,"height":1080,"elements":[{"id":"heading","rect":{"x":30,"y":10,"width":200,"height":30},"clipped":false}],"relations":[]}]}`。每个 element 来自实际浏览器测量；contains 关系写容器为 a、内容为 b，separate 关系写必须不重叠的两元素。为标题/品牌/动作、面板 head/body/foot、刻度/图例和场景标签声明适用关系，然后运行 `python3 <skill-path>/scripts/check_visual_geometry.py <snapshot.json>`。不能只测外框，不能排除已发现的冲突来迁就结果。

通过后再同尺寸查看截图，复核层次、对齐、留白和材质。该脚本不判断颜色美感、构图优劣或业务口径，不产生视觉质量评分。
