# 内容分析与来源

框架确认后再展开内容体系。阶段 1 可读材料提取业务范围，但空框架不展示从材料提取的指标和数值。

## 输入路径

- 本地文件：收集路径/附件，读取 Excel/CSV、报告、文档、JSON 或 API 说明，按需使用格式专用技能。记录文件名、sheet/页码/表格位置、版本、覆盖时间和字段定义。不能解析的部分列为缺口，不凭文件名猜内容。
- 检索生成：明确行业、地区、时间范围和用途，检索官网、统计公报、主管部门、公开年报及官方标准。保留标题、URL、发布日、数据期、检索日与引用位置。区分指标设计建议和已核对真实数值，搜索摘要不能代替原文。
- 混合输入：企业值来自本地材料，公共基准和定义来自检索。建立来源优先级；口径、周期或范围冲突时解释并确认，不静默合并。

“你来检索生成”允许研究指标体系和公开背景，不允许虚构私有经营数据。网络不可用时交付建议体系与待检索清单，明确未验证部分。

## 内容清单

每项登记：ID、业务问题、指标/非指标类型、标题、定义/公式、单位/精度、时间范围/时区、维度/粒度、聚合、来源位置、负责人或待确认项、数据状态、建议组件、槽位 ID。事件、图片、说明、流程也记录出处与有效期。

数据状态区分 provided（用户材料）、public（已核对公开来源）、derived（列计算及输入）、demo（合成演示）、missing（缺失）；这些属于来源清单，不修改协议 quality 语义。未知不填 0，不以 mock 代替生产值。

根据问题选图：趋势用时间图，比较用条形/点图，构成核对分母，空间关系才用地图。沿用生产定义；比例、去重和快照不随意求和。使用确认 token 并考虑指标好坏方向。

## 容量与核对

逐项映射槽位与优先级。过多内容先建议精简、下钻或分页；必须常驻告警不能藏入轮播。改变槽位数量/区域/地图位置时返回布局与框架预览，把旧确认标为受影响。

先核对清单事实与口径，再对照页面抽查数值、换算、分母、时区/截至时间与筛选联动。公开历史数据显示年份，不冒充实时状态。
