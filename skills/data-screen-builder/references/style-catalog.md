# 大屏视觉风格目录

风格规定标题、表面、边框、排版、数字、图表和装饰的共同语言。配色规定颜色含义，布局规定槽位与面积，空间引擎规定如何绘制地图/模型；四者独立。只改 HEX 或把三个栏目互换，不算提供了不同风格。

依据 2026-10-13 实际查看的 EasyV 客户案例、DataEase V3 模板原图、EasyV 素材广场预览，归纳以下 **15 类设计方向（10 类基础方向 + 4 类展陈强化方向 + 琉光展厅）**。这些名称、token 与 CSS 是本技能的转译，不是平台官方分类；来源与观察范围见 [调研记录](easyv-dataease-research.md)。

## 如何选

在阶段 1 明确业务主题后，同轮给 2–3 个视觉方向，附小样/参考链接、一句阅读主线和资产条件；在主题阶段记录 `visualStyle` 决定，不另加一个必须等待的新阶段。用户说“科技风”时仍要区分指挥、工程、运维或传播；没有指定时按问题、受众、屏幕环境提出推荐。不要让行业决定唯一风格，也不要把 15 类菜单当能力边界。

| --- | --- | --- | --- |

## 展陈强化方向：允许夸张，按完整视觉系统实现

用户要求“极致视觉、夸张、大片、展厅级、光效强、异形边框”时，优先从以下四类提出候选。把视觉野心写入 `stages.visualStyle.decision` 与 signature，在本次授权内实施高强度，不自行降回细线/低光的实用看板。保留真实数值、刻度与状态含义；视觉可以夸张，数据表达保持准确。

| ID / 风格 | 识别点 | 标题与边框 | 主场景与环境 |
| --- | --- | --- | --- |
| `mecha-citadel` 机甲指挥舱 | 石墨金属与装甲切面 | 多层装甲、螺钉刻线、倒角嵌槽、侧轨、散热口、窄槽流光 | 配置辖区、硬切面机械台座、机身边架 |
| `hologram-reactor` 全息反应堆 | 透光晶体与反应场 | 晶体题头、折射棱框、菱形节点、明棱暗面 | mock 展示悬浮晶核、三束光柱、分层反应环与扫描 |
| `astral-theater` 星穹剧场 | 星轨与光学曲面 | 轨道标题、椭圆透镜、大弧形框、细光学复线 | mock 展示球形星图、经纬光线、交错轨道、星云星点 |
| `gilded-palace` 鎏金殿堂 | 浮雕、漆面与金属镶嵌 | 浮雕题头、金属双镶边、卷草角花、多瓣徽章、慢扫金线 | mock 展示金属建筑展台、细窗光、金尘聚光 |

四类默认 `effects=cinematic`、`defaultIntensity=high`，分别推荐深海冰蓝、深海冰蓝、夜紫信号、曜黑香槟；配色依旧独立。大胆设计不是只把 box-shadow 调大：至少同时落实轮廓、层叠材质、光源和运动节奏。轮廓需在静止画面中可识别，光效暂停后仍是完整作品。

继续精修时读 [四类精修配方](four-style-refinement.md)。四类共用可靠的数据摘要与比例明细，独立设计徽记、框体和场景；正式绑定页面保留地理资源，空框架仍隔离业务内容。不能把“精致”理解为所有方向都收敛成琉光展厅。

`FrameOrnament.vue` 按容器实际宽高绘制 SVG 双层轮廓、角件、嵌槽及流光；不用一张边框图片拉伸到所有面板。`TitleOrnament.vue` 提供四套独立标题构图；`ScreenEffects.vue` 提供背景深度、粒子与机身结构；`SceneHalo.vue` 提供实际空间组件后的装饰舞台。标题、数据、图表和告警在独立内容层，模糊只作用于局部装饰。角花、槽口与光轨避开标签/脚注。

`framework.effectIntensity` 可选 `off/low/medium/high`，省略时用风格默认值。空框架可独立调强度、暂停并导出，完整页复用配置；光效开关不改变数据、布局或主题。`/?view=showcase` 是 mock 演示专用的动态比较入口，可切换十五类风格和九套配色、试推荐配色、强度、暂停及空间引擎；它不是用户已确认成品，HTTP 生产构建不启用演示比较模式。阶段 5 仍使用 `/?view=framework`，不以演示成品替代空框架。

同一个物流主题可以选清爽报表、黑金经营或星轨传播，分别强调统计比较、集团业绩或跨域连接。地图不是任何风格的必需品。建议配色和布局只作为起点；预览中换风格不自动更换颜色、位置、画布或地图引擎。

## 精致而饱满：琉光展厅

`luminous-gallery` 使用柔和曲面玻璃、细高光、低密度投光和有层次的数据内容。适合用户说“高强度好一点，但不够精致”“不一定要机甲”“展示饱满一点”的情况。默认动态比较入口选择此方向；保留原四类夸张方向作为明确风格需求的候选。

饱满来自每个区块的完整表达，而不是多加外框：

- 题头：更轻的曲面投光与玻璃折射，品牌/主题/时间有清楚关系，避免厚装甲压住文字。
- 指标：主值与单位、业务口径、数据状态和截至时间组成层次。比例环只在真实单位为 `%` 且值在 0–100 时绘制；其他徽记是没有数字语义的装饰，不伪造目标完成率。
- 趋势：显示最新采样、窗口峰值、有效点数，只依据当前结果；最新采样按时间字段选择，缺失不填 0，多系列不混成一条。摘要、坐标、曲线和脚注分别预留空间。
- 构成：圆环、分类数值与比例组合，保持稳定分类色；只在非负数且最多四类时启用明细配方，超过容量保留普通图例，不裁掉类别。
- 场景：模型/图文必须有自身的内容层次、材质与标注。示例 `ExhibitionScene.vue` 用同一等距投影绘制十二栋虚构建筑、立面、道路、绿化与区域标签；只在 mock 的动态比较入口使用，标注“空间概念示意 · 非实景模型”。正式框架继续使用本项目已配置地理资源，不因选择风格替换为虚构校园。
- 告警/明细：概览、级别、正文、时间和状态分开，列表/表格有统一行节奏与轻表面，不能用装饰挤掉异常。

布局保持独立，琉光方向顶部概览行在预览和完整页同为 144px；不修改槽位绑定、业务查询或数值。选定框架后再填充内容，空框架仍不加载指标摘要、图表、徽记或建筑场景。场景示意的道路流光是装饰，不表示物流或实时流量。

实现资源：`luminous-gallery.css`、`MetricMedallion.vue`、`PanelSummary.vue`、`ExhibitionScene.vue` 和图表 rich 配方。先看同尺寸整屏，再复核面板内部；存在光效不等于精致，测试通过不等于用户认可。

## 每类怎样实施

### 科技指挥

标题用一条有分段的轨道建立中心，主区域占优，次级指标降低装饰。面板以切角、顶部强调线和短定位角标形成控制台感；数字与单位仍分层。趋势采用细实线与轻面积填充，地图用同坐标标签；控制持续扫描/飞线的数量。避免每个面板都发光、用伪飞线冒充流量，或为做酷炫中心而加入无关地图。

### 极光运维

头部偏左、横向状态条稳定，面板紧凑直线，告警优先于普通业务图。图表使用较细线和低填充，表格/状态文字承担细节；正常色低亮度、异常色保留注意力。数字位数变化不推动表格列，颜色之外显示严重度。持续装饰默认关闭，不给实时告警自动翻页。适用于其他色板，不要求所有运维都绿色。

### 黑金经营

一处关键成果建立展示重点，其他指标用较小数字并配时间/单位；采用薄金属规则与较宽留白。面板头不堆图标，减少网格线，突出排名和目标差距。所谓金属感由细线、局部材质和层级实现，不给文字做强反光或把整个画面压成低对比黑色。正式数值图不使用透视柱、倾斜坐标或立体饼制造比较误差。

### 清爽报表

标题左对齐，段落、分隔线与统计图承担组织，不默认用对称装饰标题。指标区域开放，面板顶部细线，少用封闭框；用真实对比问题决定图表顺序。柱形/折线以平面、清晰坐标为主，不加纹理/辉光；脚注靠近所属图。适合有来源、时间窗口和目标线的经营说明，勿为“报表感”塞满小字。

### 柔和卡片

圆角和轻阴影区分信息岛，表面色与背景保持可读边界，标签紧跟数字；主卡面积与留白高于辅助卡。图表可较粗实线、轻填充，但保持真实刻度，不因柔和风格把全部系列变成难辨的浅色。可以用浅蓝、灰紫或暖白；同一屏采用统一圆角与阴影，不让每张卡有独立渐变。

### 工业蓝图

从设备/工序关系出发，中心可以是组态、流程或工程模型，辅助区提供状态和趋势。采用工程网格、标尺、硬边、短状态条，数字字体紧凑、标签规则。流程连线表达真实连接、流向或工序；动画只用于真实运行状态。没有模型时先做准确二维组态，不将任意建筑块称作设备孪生。

### 实景通透

资产主体承担主视觉，信息覆盖层保持低遮挡，用标签引线和清晰底板解释空间。标题与侧栏退到场景边缘，避免满屏厚卡片。先核对实际模型、照片、影像、授权与坐标；模板仅提供通透 UI 规则，**不会生成实景、建筑模型或全球场景**。需要扩展独立场景层时保持拾取、标签与底图同投影，控制遮挡与性能。

### 人文图志

围绕地点、路线、历史或文化章节组织，中心可以是地图、时间线或图文叙事，而不是机械加一个科技沙盘。衬线用于标题与章节，正文和数值保持清晰无衬线；采用细分隔和少量主题纹样。图片、地图、解说均需对应内容来源。不同地区选择自身的视觉母题，不通用添加“山水、古建筑、红色党徽”。

### 节庆盛典

从事件本身提炼一个母题，在题头或主区域集中使用；余下区域保持统计图的读数能力。可以用双框、曲线、飘带和克制放射纹，数字大小形成仪式层次；状态色与节庆色分开。模板只提供几何纹样和组件规则，品牌徽记、吉祥物或地域插画需单独素材。避免把喜庆红当异常，或所有卡片都抢主标题。

### 星轨传播

关系、传播路径或物流网络形成中心，轨道/节点只表达已声明的连接；辅助趋势与来源紧邻。可采用点阵、轨道题头、信号标记和渐进亮度，强调一个空间焦点。模板的轨道占位不是地球/网络渲染；真实地球、关系图或路线需按内容增加组件。无关系数据时选普通统计主图，不伪造边、传播量或全球飞线。

## 模板接口与能力边界

- `styles.json` 保存 15 类可运行 UI 规则的 ID、文字说明、尺寸/图表 token 与默认装饰档位；`visual-styles.css` 定义标题、面板、底纹与数字形态。完整页与框架页设置同一 `data-style`。
- `framework.json.styleId` 是正式风格选择；`paletteId`、`layoutId` 和 geography renderer 分别独立。配色 token 在风格 token 之后合并，明确品牌覆盖；不要把颜色写死在风格 CSS 内。
- 老配置省略 `styleId` 时，`visualStyle=cinematic` 对应科技指挥，其余对应清爽报表。提供 `styleId` 时以它为准；旧 `visualStyle` 只是兼容入口，不代表风格只有两类。
- `--style` 支持初建指定；比较方案可独立切换风格并导出 `styleId`。已绑定完整页按框架配置展示，显示设置不改变已确认风格。需要调整时更新候选并记录受影响的确认。
- 自定义：写 `styleId: "custom"` 和 `customStyle`（字段同内置项），并实现 `.screen[data-style=custom]` 的 CSS 或独立组件；只有 token 不能声称完成自定义形态。扩展预设时同步记录该风格适用的资产/组件要求。

## 防止再次趋同

每个候选提供“标题、面板、数字、主视觉、图表、动效”简表。候选至少在三个结构/形态维度上明显不同；不能仅改变色板、名字或发光强度。同配色同布局比较最能看清风格差异，实际成品再按业务调整布局。

定稿记录一个属于当前业务的识别点（例如真实产线结构、特定航线、地方文化路线、主要目标差距），不要每次复用地图+两侧卡片。吸收参考中的组织方式和组件配方，自己实现 CSS/SVG/图表，第三方原图仅作为观察证据，不当作新项目背景或业务数据。

空框架只检查标题、框线、表面、位置与留白；不提前画图表、业务图片、地图细节或指标。完整页再核对图表 token、主视觉资产、最长标签和各种数据状态。视觉自检与用户认可分别记录，自动通过不是用户审美认可。
