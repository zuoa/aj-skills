# 设计讨论与预览

## 最少需要了解什么

先读已有资料，再补问高影响缺口：谁看、为什么看、看到异常后做什么；屏幕尺寸/像素/宽高比、观看距离、显示设备、浏览器；展示还是值守；现有指标与数据来源；品牌及已有认可样稿。暂缺物理屏幕时以 1920×1080 桌面预览为临时默认，明确远距离可读性尚未验证。

以 [阶段流程](workflow.md) 为推进顺序，把讨论收敛为“决定—理由—预览验证位置—状态”。决定状态用 pending/proposed/confirmed/delegated/invalidated，不把建议变成用户要求。主题、色彩、布局与空框架确认之前只了解内容范围；下述数据表现形式的详细讨论在阶段 6 展开。

## 风格选择

先读 [风格目录](style-catalog.md)，区分 UI 形态、配色、布局与空间引擎。参考同一行业的不同表达，也跨行业观察同类业务问题；至少提供三个形态维度有差异的候选。风格规则同步应用框架与完整页，数字、图表线宽/柱宽/填充使用共同 token。具体主视觉和模型资产按内容决定，换配色不伪称新风格。

## 数据到表现形式

| 关系/问题 | 优先候选 | 需要判断 |
| --- | --- | --- |
| 当前水平与目标 | 指标卡、子弹图、目标线 | 单位、分母、目标区间、好坏方向 |
| 趋势与季节变化 | 折线、柱形、日历热力 | 时间间隔、缺失点、同比可比窗口 |
| 类别排名 | 水平条形、点图 | 排序、Top N、其他项、同名实体 |
| 构成 | 堆叠条形、矩形树图、少量类别环图 | 是否可加总、分母是否一致 |
| 分布与相关性 | 直方、箱线、散点 | 样本量、极值、相关不等于因果 |
| 地理、拓扑与流向 | 地图、关系图、桑基 | 空间是否确实解释问题、坐标及边权 |
| 异常与处置 | 状态、告警列表、事件表 | 严重度、时间、位置、负责人/跳转 |

避免为了组件多而增加图表。每个区块写一句它回答的问题；同一指标多次出现必须解释其用途。柱形长度比较通常从零开始，截断或变换轴需明确；不同单位不要共享隐含量纲。比例跨区域汇总、去重人数、库存快照等不能直接求和，先核对生产聚合口径。

## 构图与空间

先确定主问题和阅读顺序，再分配面积。核心总览、证据和异常可形成不同层级，不限定为“左右卡片、中间地图”。用实际最长中文标签、大数值、负值和空状态验证布局。

固定墙屏采用等比适配并居中留边，不拉伸几何。模板 `ScreenViewport.vue` 读取画布与容器的宽高，使用 `scale=min(容器宽/画布宽, 容器高/画布高)`；外层容器用动态视口高度，ResizeObserver 处理调整窗口及全屏变化，不重新创建业务查询。画布内部用设计坐标和固定网格分配可用高度，不能按浏览器宽度触发桌面重排，否则 720p 会改变构图。宽度小于 900px 的容器改为流式阅读；小于 650px 时单列。改部署目标时可以调整组件的 `reflowBelow`，不要把手机缩成整屏缩略图。

模板常规图表采用 SVG，随整体缩放保持清晰；高数据量项目可按实测切换 Canvas，但需要同时处理缩放后的像素密度及交互坐标。画布缩放和图表内部 resize 分开，图表实例监听其实际容器尺寸。实际字号仍取决于观看距离；模板的字号只能作为浏览器起点。

## 色彩空间与 token

区分品牌色、表面/文本/分隔色、分类色、连续色阶、以有意义中点为中心的发散色阶及状态色。类别按稳定实体 ID 分配颜色，不随排序变化。状态同时使用文字、图标或形状；不要仅用红绿。正向变化颜色根据指标方向判断，不在原始数据里写死颜色。

可在 OKLCH 中构造亮度和色度有序的色阶，转换并映射到目标色域；UI CSS 与 ECharts Canvas/SVG 共用已解析的 sRGB token。支持旧终端时不要假设 CSS 变量或 OKLCH 字符串能直接在 Canvas 中解析。宽色域不等于更可读；复核实际背景上的对比度、系列辨识度和投屏效果。普通文本以 WCAG AA 4.5:1、大字 3:1 为检查基准，图形重要边界也需可辨识。

## 动效与组件协作

为每种动效写明目的、触发、时长、是否持续和如何关闭。入场只在进入时执行；数据更新保留实体身份，使用短过渡；装饰动效单独控制，告警不能被轮播带走。遵循 `prefers-reduced-motion`，减少动效时关闭插值及持续动画。自动轮播/滚动提供暂停；暂停实时画面时显示暂停状态，恢复后跳到当前数据。

联动要确定共享维度 ID、影响哪些组件、选择/取消行为、时间范围和钻取返回路径。图表 click 转成“选择某维度”的语义事件，不能把 ECharts 原始事件作为跨组件协议。高亮与查询过滤分开：只有显式选择才改变查询。过滤字段不在某指标允许维度内时不应悄悄忽略，先在设计中界定其作用范围。

## 预览到定稿

区分两个预览：阶段 5 只有主题标题、框线、结构标签和留白，不加载指标或地图资源；阶段 7 才展示真实或标明来源的演示内容，并检查正常、空、过期、失败、长标签和多系列。保留具体版本与认可范围，未评审决定标为 proposed。前者需要结构确认，后者用于内容和运行验收，不能以 mock 成品代替空框架。
