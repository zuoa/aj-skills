# 指标填报

每个生成的大屏都包含指标填报功能。常规页面和显示设置中不显示填报按钮。

- 在完整大屏按 **Ctrl + Shift + E**；macOS 使用 **⌘ + Shift + E**。
- 也可以在大屏地址中加入 `?view=report`，已有其他参数时使用 `&view=report`。这适用于触屏设备。关闭填报后会移除该参数。
- `?view=framework` 只展示空框架，不提供业务填报。

选择指标，修改记录、数值和数据截至时间，点击“保存并更新大屏”。数字卡、图表、排名、表格和地图读取同一份填报结果。多个组件共享同一查询时会一起更新。分组或趋势支持添加、删除记录；空白表示未知 `null`，`0` 表示已知零，删除全部记录并保存表示暂无数据。数据截至时间和时间序列按本机时区输入，展示时沿用查询时区。地图区域 ID 必须与边界资源中的 ID 对应。

填报采用浏览器 `localStorage`，按站点、页面路径、大屏 ID、指标、筛选、维度、时间窗口长度、时区、粒度及排序/条数条件隔离。每分钟滚动的同长度时间窗口继续使用填报；不同区域、24 小时与 7 天等范围分别填报。打开填报时锁定当前范围，避免填写过程中随时钟变化。填报不自动计算其他范围的总量、比例或去重值。

保存后立即更新，暂停更新时也可保存；页面刷新、定时刷新和接口返回不会覆盖已保存的填报。同源同路径的其他标签页通过存储事件同步已保存的结果；尚未保存的表单不会被替换。填写值标记为“本地填报”，仍按实际数据截至时间提示过期。

在填报界面点击“恢复原始数据”，确认后移除当前指标、当前范围的填报，恢复配置的 mock 或 HTTP 数据源。暂停状态下移除后需恢复更新，才能重新读取原始数据。HTTP 失败正常显示错误，不切换模拟数据。指标定义或结果结构变化时，不兼容的旧填报会被忽略，需重新填写。

数据仅存于当前浏览器，不上传服务器，也不会自动同步到其他设备或浏览器。清理站点数据会删除填报；浏览器禁用存储或空间不足时，保存会报错且修改不生效。隐藏入口只用于保持展示页面简洁，不提供身份认证；需要权限控制或多人协作时应接入现有后端。
