# 规划文本自检清单

用于定稿前的两轮校验；涉及最新政策、重大投资或敏感公共议题时做第三轮时效校验。

## 第一轮：成立性检查

- 规划类型是否明确为 `regional` 或 `specialized`
- 规划层级、规划主体、规划范围、规划期是否明确
- 基期年、目标年、展望年是否统一
- 是否写清与上位规划、同级发展规划、相关专项规划、国土空间规划的关系
- 规划结构是否符合对应类型的最低要求
- 关键政策名称、机构名称、年份、数据是否准确
- `04-source-log.md` 是否保留了原始发布页 URL
- 指标是否有基期值、目标值、单位和口径说明
- 重大项目是否至少说明成熟度、牵头主体和对应任务
- 是否存在与上位规划明显冲突的提法
- 是否把行动倡议、招商口号或研究建议误写成法定规划表述

任何一项明显不成立，都不能进入定稿。

## 第二轮：质量检查

- 发展基础是否为后文目标和任务提供了证据支撑
- 目标、指标、任务、项目、保障措施是否闭环
- `regional` 是否写出了空间格局、功能分工和协同机制
- `specialized` 是否写出了重点任务、重大工程项目和保障措施
- 是否存在大量空话套话、宣传腔或论文腔
- 是否把愿景当作确定性承诺
- 是否存在“每章都重要、但没有轻重缓急”的平均用力问题
- 是否把项目库写成了愿望清单
- 实施矩阵是否明确责任、时序和评估方式
- 章节层级是否过深，是否出现机械堆砌材料

如果全文只剩原则表态，没有抓手和责任闭环，视为未通过。

## 第三轮：时效与程序检查

在以下情形执行：

- 用户要求最新政策或最新统计数据
- 涉及大额投资、重大工程、约束性指标
- 涉及环境、安全、社会稳定、公共服务敏感议题
- 用户要求“正式报批版”“可上会版”

重点检查：

- 政策和数据是否仍然有效
- 是否存在更新的上位规划或主管部门口径
- 是否需要补充合法性审查、公平竞争审查、环评、稳评提示
- 是否已经说明立项、征求意见、专家论证、衔接审查等程序状态
- 是否混入无法核实的项目投资、土地、产值、覆盖人数等数字
- 是否把未批项目写成确定实施项目

## 终稿通过条件

1. 规划属性成立
2. 上位衔接清楚
3. 指标和项目可复核
4. 任务与保障措施闭环
5. 行文像规划文本
6. 关键程序风险已提示
