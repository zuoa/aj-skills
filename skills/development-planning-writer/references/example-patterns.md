# 公开范例与可借鉴写法

以下范例只提炼结构和方法，不照抄措辞。

## 1. 区域规划范例：`成渝地区双城经济圈建设规划纲要`

来源：

- 规划全文：https://www.ndrc.gov.cn/fggz/fzzlgh/gjjzxgh/202112/t20211201_1306578.html
- 官方答问：https://www.ndrc.gov.cn/xwdt/xwfb/202110/t20211021_1300582_ext.html

可借鉴点：

- 先用前言和背景交代为什么必须做这个区域规划。
- 战略定位非常明确，先回答区域在全国发展格局中的位置，再展开任务。
- 同时设置 `2025` 阶段目标和 `2035` 远景目标，适合区域规划的长周期属性。
- 强调“双核引领、区域联动”等空间和功能关系，而不是简单列部门任务。
- 基础设施、产业、创新、公共服务、生态、安全、开放合作等任务都是围绕“区域协同”来写。

适合学习的场景：

- 都市圈、协同区、经济带、片区联动规划
- 需要写清功能分工、节点关系和协同机制的区域规划

## 2. 专项规划范例：`“十四五”数字经济发展规划`

来源：

- 规划全文：https://www.ndrc.gov.cn/fggz/fzzlgh/gjjzxgh/202203/t20220325_1320207.html
- 官方解读：https://www.ndrc.gov.cn/xxgk/jd/jd/202201/t20220113_1320269_ext.html

可借鉴点：

- 先总结发展阶段变化和现实基础，再提出总体要求。
- 结构非常稳定：总体要求 -> 发展目标 -> 重点任务 -> 保障措施。
- “基础支撑、产业发展、公共服务、治理安全”几个板块之间逻辑清晰，适合大多数专项规划。
- 解读材料强调“体系化设计、系统化布局”，说明专项规划不应只是碎片化工作罗列。

适合学习的场景：

- 数字化、产业、公共服务、治理类专项规划
- 需要把多项任务组织成清晰任务体系的规划

## 3. 地方专项规划范例：`深圳市现代建筑业高质量发展“十四五”规划`

来源：

- 通知页：https://www.sz.gov.cn/cn/xxgk/zfxxgj/ghjh/csgh/zxgh/content/post_9772801.html
- 规划 PDF：https://www.sz.gov.cn/attachment/0/969/969607/9772801.pdf
- 新闻摘要：https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_9776092.html

可借鉴点：

- 目录结构非常规范：引言 -> 发展背景 -> 总体要求 -> 主要任务 -> 保障措施。
- 目标部分给出一组明确的量化指标，新闻摘要还展示了指标如何对外解释。
- 任务部分围绕行业关键转型方向展开，不是平均用力。
- 保障措施单列，有助于避免规划停留在任务清单层面。

适合学习的场景：

- 地方部门五年专项规划
- 需要量化行业发展目标并配套重点任务、项目和保障措施的规划

## 4. 民生类专项规划范例：`深圳市住房发展“十四五”规划`

来源：

- 新闻摘要：https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_9520149.html

可借鉴点：

- 民生领域规划适合使用“供给目标 + 结构安排 + 制度措施”的表达方式。
- 目标不只是抽象愿景，而是直接落到供地、建设、供应分配等量化任务。
- 任务部分天然对应多元政策工具，适合写成“保基本、广覆盖、促宜居”这类主线。

适合学习的场景：

- 住房、养老、托育、教育、卫生等公共服务规划
- 需要把公共供给规模、服务质量和制度安排一起写清的规划

## 5. 最新地方实务要求范例：`江阴“十五五”市级专项规划编制指引`

来源：

- PDF：https://www.jiangyin.gov.cn/uploadfiles/202601/15/2026011514031022573580.pdf

可借鉴点：

- 把专项规划编制拆成目录清单、时间节点、征求意见、专家论证、衔接审查、批准公布等完整流程。
- 非常适合拿来反推“编制说明”应该写什么、“程序性材料”应该准备什么。
- 明确强调专项规划草案与同级发展规划、上位专项规划相抵触时必须修改。

适合学习的场景：

- 用户要求“正式送审工作稿”
- 需要同步准备编制说明、意见采纳、风险提示时

## 6. 提炼后的最佳实践

- 区域规划先写“定位和格局”，专项规划先写“目标和任务”。
- 正文用稳定公文结构，亮点体现在证据和逻辑，而不是花哨文风。
- 用 `目标 -> 指标 -> 任务 -> 项目 -> 保障 -> 评估` 的闭环控制整篇结构。
- 对跨区域协同和重大项目，优先写机制与路径，少写无法核实的精确数字。
