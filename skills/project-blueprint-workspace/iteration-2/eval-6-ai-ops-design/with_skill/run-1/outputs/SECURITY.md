# 安全与隐私

## 风险范围

内部开发团队控制台包含生产回滚等高权限动作。身份、环境级授权、职责分离、审计先于便利性；AI 建议不得拥有执行凭据或绕过确定性策略。

## 数据清单

| 数据 | 分类 | 用途 | 访问 | 保留/删除 | 状态 |
|---|---|---|---|---|---|
| 告警、服务和部署元数据 | internal/confidential provisional | 研判与预检 | 按服务和环境授权 | TBD-SECURITY-003 | pending |
| 影响确认与回滚操作 | confidential provisional | 协作、执行与复盘 | 操作者、审批者、审计员 | TBD-SECURITY-003 | pending |
| AI 输入、引用与输出 | confidential provisional | 辅助研判 | 不授予执行权限 | TBD-AI-001 | pending |

## 信任边界与控制

| 边界/动作 | 威胁 | 控制 | 验证 |
|---|---|---|---|
| 浏览器至 API | 会话劫持、越权 | 企业 SSO、短期会话、CSRF 防护、服务端授权 | 身份与权限集成测试 |
| API 至部署系统 | 重放、目标替换 | 短期机器身份、幂等键、提交时重检服务/环境/版本 | 重放和竞态测试 |
| AI 辅助边界 | 提示注入、伪造证据、越权工具调用 | 最小上下文、来源白名单、输出结构校验、只读工具、人与确定性规则批准 | 对抗评测和权限负测 |
| 审计写入 | 删除或篡改记录 | 追加式存储、受限写入、关联 ID；必需审计失败则拒绝回滚 | 篡改与故障注入测试 |

## 身份与访问

查看、确认影响、批准和执行回滚是不同权限。生产回滚默认要求重新认证或等价的近期强认证，并显示当前身份、环境和目标版本。具体 IdP、角色与审批矩阵由 `TBD-SECURITY-002` 决定。

## 应用与供应链

- 所有外部字段按不可信输入处理；日志和提示上下文做密钥与个人数据脱敏。
- 密钥进入专用 secret provider，禁止进入仓库、构建日志和浏览器。
- 锁定依赖、生成 SBOM、扫描已知漏洞；修复时限由安全负责人定级。
- 记录登录、查看敏感证据、影响确认、审批、执行、取消、失败和策略变更事件。

## 事件响应

安全事件按组织现有值班渠道路由；在 `TBD-SECURITY-001` 指定负责人前不可视为 production-ready。证据保全、通知义务和具体保留期由数据与地区盘点决定。
