# Coding agent 项目规则

以 [ENGINEERING.md](ENGINEERING.md) 为代理无关的工作流与质量门禁来源。产品、行为、体验、内部边界、安全和运行分别以 [PRD.md](PRD.md)、[SPEC.md](SPEC.md) 与 `specs/`、[DESIGN.md](DESIGN.md)、[ARCHITECTURE.md](ARCHITECTURE.md)、[SECURITY.md](SECURITY.md) 和 [DEPLOY.md](DEPLOY.md) 为准；长期决定位于 `docs/adr/`。

实现前列出实质假设和冲突。采用满足已确认规格的最小改动，运行 ENGINEERING.md 中适用检查。状态不能只靠图形表达；团队界面的 Emoji 默认禁用，唯一品牌例外必须严格遵守 DESIGN.md。蓝图与请求冲突时先更新权威文档。
