## 当前推荐的最小闭环

```text
教练建立可预约课程与可用时段
        ↓
获得公开预约链接
        ↓
学员在手机网页选择时段并提交必要信息
        ↓
系统避免同一时段被重复占用并生成预约
        ↓
教练在管理端查看预约，学员看到明确结果
        ↓
双方可按已确认规则取消或调整
```

这个闭环优先验证“教练是否愿意持续发布可约时间、学员是否能独立完成预约”。支付、会员体系、营销增长、复杂排课和原生 App 暂不自动纳入首版。

## 蓝图的使用方式

- 先处理 `05-open-decisions.md` 中的阻塞项，再确认 MVP。
- 用真实教练的课程与排期走查 `02-user-flows.md`。
- 在业务规则获得确认前，不把“候选规则”固化成代码。
- 每次范围变化时同步更新蓝图和验收条件。
