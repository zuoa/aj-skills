# 04. 决策、交付与评审清单

## 1. 关键架构决策（ADR 摘要）

| 决策 | 选择 | 理由 | 代价/触发复审 |
|---|---|---|---|
| 区域模型 | CN/EU/US 独立数据平面 | 数据驻留、故障隔离、供应商本地化 | 运维与发布成本增加；进入新法域时复审 |
| 租户归属 | 创建时绑定 `home_region` | 路由清晰，减少误传 | 迁移需离线工具、法务批准与客户窗口 |
| 服务形态 | 模块化单体 + 异步 worker 起步 | 更快交付并保持领域边界 | 团队/吞吐达到阈值后按领域拆分 |
| 多租户存储 | 共享库强隔离，支持大客户 silo | 成本与企业隔离需求平衡 | 隔离测试失败或合同要求时转 silo |
| 发票处理 | 隔离桶 + 区域 OCR | 控制恶意文件与驻留风险 | 供应商无法区域化时改自托管/替换 |
| 支付 | 区域 provider adapter，令牌化 | 减少敏感数据范围，便于更换供应商 | 直接处理资金/完整账号前必须专项评审 |
| 灾备 | 同法域 warm-standby | 支持 15 分钟/2 小时目标 | 演练不达标则提升热备等级 |

## 2. 分阶段交付

### 阶段 0：风险消减与基础设施

- 锁定各区域云、IdP/OCR/通知/支付候选与数据处理位置。
- 完成数据流图、威胁模型、租户隔离 PoC、支付状态机 PoC、恢复 PoC。
- 建立区域账户/项目、IaC、CI/CD、密钥、日志和生产访问基线。

退出条件：法务/安全阻断项有明确结论；恢复 PoC 支持目标；关键供应商有替代方案。

### 阶段 1：核心费用闭环

- Web/移动端登录、发票上传、费用单、审批、预算占用/释放、审计。
- 企业管理员管理组织、角色、预算与审批流版本。
- 欧盟区域先行验证驻留控制；自动化跨租户负向测试进入发布门禁。

退出条件：端到端流程、权限、删除、备份恢复和可观测性验收通过。

### 阶段 2：支付与区域扩展

- 接入各区支付 adapter、托管式付款资料采集、对账和异常处理。
- 上线中国/美国数据平面；验证区域供应商、运维路径与灾备。
- 增加 SCIM、代理审批和财务导出（按客户优先级）。

退出条件：支付故障注入无重复付款；每区完整灾备演练达到 RPO/RTO。

## 3. 可追踪验收样例

| 需求 | 验收方法 |
|---|---|
| 员工上传发票 | Web/移动端上传、断点/失败重试、恶意文件拒绝、上传后临时文件清理 |
| 经理审批 | 正确链路、并发决定冲突、越权拒绝、代理到期、审计可追踪 |
| 管理员配置预算 | 版本生效、并发占用不超算、变更权限、历史可重放 |
| 企业 SSO | OIDC/SAML 正反向测试、签名/issuer/audience/时钟、账号停用 |
| 第三方支付 | 幂等、超时、重复 webhook、乱序事件、未知结果、日终对账 |
| 多租户 | API/数据库/缓存/对象/搜索/队列的跨租户负向测试 |
| 欧盟数据驻留 | 资源清单、网络流、日志/备份/支持访问和供应商处理位置核验 |
| RPO/RTO | 每区实测恢复报告：恢复点差值 ≤15 分钟、核心恢复 ≤2 小时 |

## 4. 必须确认的开放问题

### 法务负责人 **[LEGAL]**

- 合同如何定义欧盟客户、客户数据、数据驻留边界与分包商？
- CN/EU/US 各区的处理者/控制者角色、处理基础、隐私通知和数据主体请求流程是什么？
- 发票、审批、支付、审计和备份分别保留多久；法律保留如何覆盖删除请求？
- 全球支持、反欺诈信号、遥测、崩溃报告、邮件/推送是否允许跨境；需要何种传输机制？
- 中国个人信息/重要数据跨境机制、数据本地化、备案/许可及密码要求是否触发？
- 各区支付角色是否涉及牌照、KYC/AML、制裁、税务或消费者保护义务？
- 事件通知的法域、门槛、对象与时限是什么？

### 安全负责人 **[SECURITY]**

- 批准数据分类、威胁模型、租户隔离方案、管理员/支持访问和职责分离矩阵。
- 批准 MFA、会话、设备/移动端存储、加密、KMS/HSM、密钥轮换与日志脱敏基线。
- 评审 SSO/SCIM、发票文件、OCR、支付托管组件、webhook 和供应商安全。
- 明确漏洞门槛、渗透测试范围、告警升级、事件响应和证据保全流程。
- 批准备份不可变性、恢复身份、灾备演练结果和未达标风险接受流程。

### 产品/业务负责人 **[BUSINESS]**

- 定义预算超限行为、审批代理/升级、汇率来源、税务字段和支付失败人工流程。
- 明确 2 小时内必须恢复的功能、正式 SLO、支持时区和企业数据导出格式。
- 明确租户跨区迁移是否为产品能力；默认方案是不提供自助迁移。

## 5. 评审通过定义

蓝图评审通过意味着：架构方向和待办责任人已被认可，阻断项已有结论或限期计划。它不意味着系统已通过渗透测试、灾备验证、法律审查或任何外部合规认证。
