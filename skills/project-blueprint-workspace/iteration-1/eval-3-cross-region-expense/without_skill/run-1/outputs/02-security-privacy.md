# 02. 安全与隐私蓝图

## 1. 控制目标

| 风险 | 设计控制 | 评审证据 |
|---|---|---|
| 跨租户越权 | 强制租户上下文、数据库侧隔离、对象级授权、负向测试 | 自动化隔离测试与审计样本 |
| 账号接管 | 企业 SSO、短会话、敏感操作再认证、管理员 MFA 候选 | IdP 配置测试、会话策略 |
| 发票恶意文件 | 隔离上传、内容嗅探、大小限制、AV/沙箱、下载安全头 | 测试样本与阻断记录 |
| 支付篡改/重复付款 | 职责分离、双人复核阈值、幂等、webhook 验签、对账 | 状态机与故障注入结果 |
| 数据泄露 | TLS、静态加密、区域 KMS、字段最小化、导出审批、DLP 候选 | 密钥/访问/导出记录 |
| 内部人员滥用 | JIT 最小权限、生产禁用共享账号、双人批准、会话审计 | 访问复核与告警记录 |
| 供应链风险 | 锁定依赖、SAST/SCA/密钥扫描、制品签名、SBOM | CI 门禁与制品证明 |
| 勒索/误删 | 不可变备份、独立备份权限、恢复演练 | 恢复报告 |

## 2. 身份与权限

- 员工、经理、企业管理员、财务/付款操作员、审计员、平台支持为独立角色；审批人与付款释放人默认职责分离。
- 审批权限同时检查租户、组织关系、费用单状态、金额/币种和代理有效期。
- SCIM 自动开通/停用可作为企业功能；停用应撤销会话与未使用的 API token。
- 服务间身份使用短期工作负载凭证；密钥进入区域密钥/秘密管理服务，不进入仓库、镜像或日志。
- Break-glass 账户离线保管、强 MFA、限时启用并触发实时告警。

**[SECURITY]** 批准角色矩阵、MFA 覆盖面、会话时长、金额阈值、支持人员访问流程和 break-glass 方案。

## 3. 加密与密钥

- 传输使用当前批准的 TLS 配置；数据库、对象、备份、队列和日志静态加密。
- 每区域独立 KMS 与密钥管理员；生产/非生产、业务数据/备份分开密钥。
- 高敏字段可使用信封加密；支付令牌和银行掩码字段禁止写日志。
- 定义密钥轮换、撤销、备份和灾难恢复流程；记录所有解密与密钥管理操作。

**[SECURITY]** 定稿算法/协议基线、客户自管密钥需求、HSM 要求、轮换周期和密钥驻留规则。  
**[LEGAL]** 确认中国区密码产品、密钥托管与监管要求。

## 4. 隐私与数据生命周期

- 采集前明确用途和必填性；OCR 结果不得用于模型训练，除非获得单独、有效授权。
- 按租户配置的法定/合同保留策略执行；到期删除主数据、索引、缓存和派生数据，备份按既定周期自然过期并限制恢复后的再删除窗口。
- 提供访问、更正、删除、导出、限制处理等请求的工单流程，但能否执行及例外由法务判定。
- 生产数据不得复制到测试；支持排障优先使用脱敏诊断包。
- 分析指标以区域内聚合为主；跨区只允许不可逆、低粒度且经批准的运营指标。

**[LEGAL]** 确认 GDPR 角色与处理基础、DPA/SCC 或其他传输机制、数据主体请求 SLA、儿童/雇员数据规则、各区发票税务留存期及合法保留例外。  
**[LEGAL]** 针对中国确认《个人信息保护法》相关角色、单独同意/告知、敏感个人信息、跨境评估/认证/标准合同触发条件；本草案不作适用性结论。  
**[LEGAL]** 针对美国确认适用的州隐私法、消费者/雇员数据豁免和州级数据泄露通知要求。

## 5. 安全监控与响应

- 告警：异常登录、跨租户访问拒绝激增、管理员提权、大额/重复支付、银行资料变更、批量导出、密钥操作、备份删除尝试。
- 审计事件包含谁、何时、租户、动作、对象、结果、来源、关联 ID；不记录发票正文、认证令牌或完整银行信息。
- 建立区域化事件响应手册、证据保全、供应商升级与客户通知流程；至少每年桌面演练，支付与跨租户事件优先演练。

**[SECURITY]** 完成威胁建模、渗透测试、移动端安全评估、供应商评审与上线风险签字。  
**[LEGAL]** 审定各区事件通知对象、触发标准与时限；监控数据跨境查看需单独确认。

## 6. 上线安全门槛（不是认证结论）

- 无已知未接受的严重/高危漏洞；例外需风险所有者、到期日和补救计划。
- 租户隔离、IDOR、SSO、文件上传、支付重放与管理员权限测试通过。
- 关键秘密无硬编码，生产访问和密钥访问可审计。
- 数据流图、处理者清单、保留/删除矩阵与事件响应联系人已批准。
- 这里的通过只表示内部发布条件满足，不代表获得或符合某项认证。
