# 产品范围与验收规格

## 1. 目标与成功指标

### 1.1 产品目标

- 用户在 3 分钟内完成注册并开始首个训练计划。
- 用户用不超过 30 秒完成一次无照片打卡，或不超过 90 秒完成带照片打卡。
- 教练在网页端可批量管理学员计划，并快速识别漏练用户。
- 提醒可配置、可退订、可追踪，但不造成骚扰。

### 1.2 MVP 北极星与护栏指标

| 类型 | 指标 | 上线后 8 周目标 | 说明 |
|---|---|---:|---|
| 北极星 | 每周完成至少 3 次打卡的活跃用户比例 | ≥ 30% | **provisional**；重评：首批 2,000 用户满 4 周 |
| 激活 | 注册后 24 小时内完成首次打卡 | ≥ 45% | 同上 |
| 留存 | 新用户 D7 留存 | ≥ 25% | 同上 |
| 教练效率 | 创建并分配一份 7 天计划耗时 P50 | ≤ 5 分钟 | 可用性测试验证 |
| 可靠性 | 打卡提交成功率 | ≥ 99.9% | 排除客户端离线且未重试 |
| 护栏 | 推送关闭/退订率（周） | ≤ 5% | 超限需检查频率与文案 |
| 护栏 | 照片投诉率 | < 0.1% | 投诉/上传照片数 |

## 2. 角色与权限

| 角色 | 能力 | 数据边界 |
|---|---|---|
| 会员 | 管理本人资料、查看被分配计划、打卡、上传/删除本人照片、设置提醒、导出/注销 | 仅本人数据及分配给本人的内容 |
| 教练 | 创建计划模板、分配给名下会员、查看名下会员完成情况与授权照片、记录内部备注 | 仅明确建立教练关系的会员 |
| 运营管理员 | 管理账号状态、处理举报、查看必要运营指标、配置模板 | 依岗位最小授权；查看照片需原因与审计 |
| 客服 | 查询账号/任务状态、发起工单 | 默认不可查看照片与教练备注 |
| 系统任务 | 发送提醒、缩略图、清理过期数据 | 仅服务身份所需权限 |

教练不得自行搜索或绑定任意手机号；关系由会员邀请码确认或管理员导入后由会员确认。关系解除后立即失去后续数据访问权，历史访问保留审计。

## 3. 核心用户旅程

### 3.1 注册与登录

1. 用户输入中国大陆手机号并同意用户协议、隐私政策。
2. 服务端进行图形/行为验证（风险触发式）和频控，发送 6 位验证码。
3. 验证码正确后创建或登录账号；新用户补充昵称和时区，敏感信息授权分开勾选。
4. 服务端签发短期 access token 和可轮换 refresh token。

验收：验证码 5 分钟失效、单次使用；同手机号 60 秒内不可重复发送；连续错误 5 次使该验证码失效；错误信息不泄露手机号是否注册。

### 3.2 训练计划

1. 会员查看当前周日历与每日训练任务。
2. 打开任务查看动作、组数/次数/时长、注意事项和演示媒体（MVP 可仅图片/文字）。
3. 会员可开始并完成任务；计划版本锁定，教练修改模板不追溯已分配实例。
4. 教练创建模板、添加训练日/动作、预览并发布，再分配给会员并选择起始日期。

验收：跨时区按用户设置时区确定“当天”；计划变更对用户可见且有更新时间；重复分配需二次确认。

### 3.3 每日打卡与照片

1. 用户选择当天计划任务，填写感受（1–5）、训练时长和可选备注。
2. 可选上传 0–3 张照片；客户端先压缩并剥离 EXIF/GPS。
3. 客户端从服务端取得限时直传凭证，直传对象存储，随后提交打卡。
4. 服务端异步校验类型/大小、生成缩略图和执行安全扫描；失败照片隔离且不影响文字打卡。
5. 同一天同一任务默认只有一条打卡，可编辑；服务端保存更新时间和审计记录。

验收：支持 JPEG/PNG/HEIC 输入，服务端规范化为 JPEG/WebP；单张原图上限 10 MB；弱网重试不产生重复打卡；用户可删除照片且 24 小时内从在线存储不可访问。

### 3.4 提醒

1. 用户默认关闭营销消息；训练服务提醒在明确授权后开启。
2. 用户选择本地时间、星期、静默时段与渠道；默认每日最多 1 条训练提醒。
3. 调度器按用户时区入队；发送前检查任务是否已完成、账号状态及最新授权。
4. 点击推送深链至当天任务；记录送达（供应商可提供时）、点击与退订。

验收：关闭后 5 分钟内不再生成新任务；静默时段不发送；同一提醒具备去重键；厂商通道不可用时不自动改用短信。

### 3.5 教练网页端

- 登录与会话管理；MVP 沿用手机号验证码，敏感操作二次验证。
- 学员列表：昵称、计划、近 7 天完成率、最近打卡；支持状态筛选与分页。
- 计划模板：草稿、发布、归档；动作排序、训练日复制、预览。
- 分配：选择学员、起始日、备注；单次最多 100 人。
- 学员详情：完成趋势、打卡详情、经授权照片；访问照片写审计日志。
- 权限与退出：15 分钟无操作锁屏，8 小时会话过期。

## 4. 用户故事优先级与验收

| ID | 优先级 | 用户故事 | 验收摘要 |
|---|---|---|---|
| AUTH-01 | P0 | 会员用手机号验证码登录 | 合法手机号、频控、验证码生命周期、token 轮换均通过 |
| PLAN-01 | P0 | 会员查看今日/本周计划 | 空态、加载态、历史版本、时区边界正确 |
| PLAN-02 | P0 | 教练创建、发布、分配计划 | 草稿校验、版本化、权限、批量分配可审计 |
| CKIN-01 | P0 | 会员提交/编辑当天打卡 | 幂等、弱网重试、时间边界、并发编辑正确 |
| MEDIA-01 | P0 | 会员上传/删除打卡照片 | 直传、格式/大小校验、EXIF 清除、私有读取 |
| PUSH-01 | P0 | 会员设置并接收训练提醒 | 授权、静默期、去重、深链、退订生效 |
| COACH-01 | P0 | 教练查看名下学员完成情况 | 数据隔离、分页筛选、审计日志 |
| PRIV-01 | P0 | 用户导出与注销账号 | 身份复核、冷静期、删除/匿名化状态可追踪 |

## 6. 非功能产品要求

- 移动端支持最近两个 iOS 大版本；Android 8.0+。**provisional**，重评：埋点显示不支持设备占目标用户 > 3%。
- Web 支持最近两个稳定版 Chrome/Edge/Safari，以及主流国产 Chromium 浏览器。**provisional**，重评：真实流量中其他浏览器占比 > 5%。
- 响应式断点：360、768、1024、1440 px；教练端 1024 px 以下保留只读核心功能，复杂编辑提示使用桌面端。
- 所有用户可见时间按账户时区显示；默认 `Asia/Shanghai`。
- 中文简体为唯一 MVP 语言；文案外置以便国际化。
- 无障碍目标参照 WCAG 2.1 AA 的可操作部分：正文对比度 ≥ 4.5:1、焦点可见、表单错误可读屏。

## 7. 明确非目标

- 付费订阅、电商、直播/视频课、AI 动作识别、社交动态、饮食记录、可穿戴设备同步。
- 教练与学员即时聊天；MVP 使用计划备注，不构建 IM。
- 复杂多租户计费；数据模型保留 `organization_id`，但不承诺自助开通机构。
- 医疗诊断、康复处方或健康疗效承诺；产品文案明确非医疗建议。
