# 健身习惯产品项目蓝图（中国大陆 MVP）

版本：v1.0  
日期：2026-09-10  
状态：供立项、排期与技术评审使用

## 1. 项目一句话

面向中国大陆用户的跨端健身习惯产品：用户可用手机号登录、查看训练计划、每日打卡并上传照片、接收提醒；教练通过网页端编排计划并查看学员执行情况。

## 2. 已知约束

- 客户端：iOS、Android、响应式 Web。
- 客户端团队：3 名 Flutter 工程师。
- 后端团队熟悉 TypeScript。
- 固定 MVP：手机号登录、训练计划、每日打卡、照片上传、提醒推送、教练网页端。
- 交付时间：6 个月。
- 初期规模：约 20,000 DAU。
- 月基础设施预算上限：人民币 8,000 元（不含人力、短信、应用商店账号与内容审核人工）。

## 3. 建议结论

- Flutter 单代码库覆盖会员 iOS/Android/Web，并以独立入口构建教练 Web，复用领域模型、网络层和设计系统。
- TypeScript + NestJS 模块化单体；PostgreSQL 为事实源，Redis 做验证码/缓存/限流，对象存储 + CDN 承载照片，任务队列执行推送和图像处理。
- 部署在中国大陆单一云厂商、单地域多可用区；保持无状态服务可横向扩展，并抽象短信、对象存储与推送供应商。
- 从 MVP 即落实敏感个人信息单独同意、照片私有存储、最小权限、审计、删除与导出流程。
- 以 12 个双周 Sprint 推进，S10 功能冻结，S11 灰度，S12 上线与稳定。

## 5. MVP 上线定义（Definition of Done）

只有同时满足以下条件才可正式上线：

1. P0/P1 用户故事通过验收，P0 缺陷为 0；P1 缺陷有负责人、规避方案和关闭日期。
2. iOS、主流 Android 厂商渠道和响应式 Web 的关键路径通过真机/浏览器回归。
3. 20,000 DAU 基线压测及 3 倍峰值演练通过，核心 API 达到本文 SLO。
4. 隐私政策、用户协议、敏感信息单独同意、注销/删除、导出流程完成法务确认。
5. 网站 ICP、App 备案与应用商店材料按实际上线形态完成；等保定级结论已记录并执行。
6. 备份恢复、推送降级、短信供应商异常、对象存储临时凭证泄露应急演练通过。
7. 埋点看板、告警、值班、回滚与客服升级通道可用。

## 6. 变更控制

- P0 范围变更需产品负责人、技术负责人共同批准，并同步影响上线日期或删减同等工作量。
- 架构、安全、数据留存变化以 ADR 形式补充到 `07-decisions-assumptions.md`。
- 所有标为 **provisional** 的结论，在其重评条件触发时进入最近一次架构/产品评审；未触发时也在每月末集中复核。
