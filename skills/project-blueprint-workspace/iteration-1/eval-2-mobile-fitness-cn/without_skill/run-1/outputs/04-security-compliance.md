# 安全、隐私与中国大陆合规规范

> 本文是工程与产品基线，不替代持证中国律师、备案服务商和等保测评机构的正式意见。

## 1. 数据分类

| 级别 | 示例 | 控制 |
|---|---|---|
| L4 敏感个人信息/高风险 | 训练照片、由内容推断的健康/身体状态、身份验证凭据 | 单独同意、强加密、细粒度授权、访问审计、最短留存 |
| L3 个人信息 | 手机号、设备 token、IP、教练关系、训练记录 | 加密/脱敏、目的限制、导出删除流程 |
| L2 内部 | 聚合运营指标、非敏感配置、匿名故障数据 | 员工权限、禁止公开 |
| L1 公开 | 已发布的通用训练动作说明 | 完整性与版权管理 |

训练照片一律按 L4 处理，即使法务最终分类不同也不降低技术控制。自由文本可能含健康信息，不进入日志和通用分析平台。

## 2. 合规工作流

### 2.1 上线前必须完成

- 明确运营主体、服务器与域名主体；完成网站 ICP 备案、公安备案（如适用）和移动互联网应用程序备案/应用商店材料。
- 依据《个人信息保护法》《网络安全法》《数据安全法》完成数据清单、处理目的、最小必要性、第三方清单与个人信息保护影响评估（PIPIA）。
- 对照片、可能反映健康状态的数据取得醒目、具体的单独同意；拒绝照片授权不影响无照片打卡。
- 首次启动在收集任何非必要数据前展示隐私摘要；隐私政策列明 SDK 名称、主体、目的、数据类型、权限与政策链接。
- Android/iOS 权限按功能触发申请：相机、相册、通知分开；拒绝后仍可完成核心流程。
- 建立未成年人策略。MVP 建议仅面向 18 岁及以上；注册时声明年龄门槛且营销定向不得触达未成年人。
- 确认等保定级。**provisional**：按等保二级目标设计与准备；重评：主管部门/测评机构要求三级，业务被认定为重要系统，或处理规模/影响显著上升。
- 数据保存在中国大陆区域；禁止把生产个人信息发送到境外日志、崩溃、分析或 AI 服务。跨境需求必须先完成法律路径和 PIPIA。

### 2.2 同意目的拆分

| purpose code | 是否核心必需 | 说明 |
|---|---|---|
| `terms_and_privacy` | 是 | 账号和核心服务所需基础处理 |
| `sensitive_fitness_data` | 是/单独同意 | 处理可能反映健康状态的训练记录 |
| `checkin_photo` | 否/单独同意 | 上传、处理、向授权教练展示照片 |
| `service_push` | 否 | 训练提醒，可随时关闭 |
| `analytics_optional` | 否 | 非必要产品分析 |

同意证据记录政策版本、界面版本、时间、来源与结果；撤回与给予同样容易，撤回不影响此前合法处理，但停止后续非必要处理。

## 3. 数据主体请求

- 入口：App/Web 账户设置；无法登录者由客服工单完成增强身份核验。
- 支持：查阅/复制（JSON/CSV + 媒体包）、更正、撤回同意、解除教练关系、删除照片、注销账号。
- 响应时限：内部目标 15 个工作日（**provisional**）；重评：法务确定更短法定/合同期限或用户规模导致积压。
- 导出包使用一次性链接，24 小时失效，下载前二次验证；导出生成与下载均审计。
- 注销设置 7 天冷静期（**provisional**），期间停用教练访问和提醒；法律不允许延迟的删除请求立即执行。重评：法务意见、商店规则或投诉表明冷静期不适用。

## 4. 留存与删除

| 数据 | 在线留存基线 | 到期动作 |
|---|---|---|
| OTP 明文/验证码 | 最长 5 分钟 | 自动失效删除；日志不得记录 |
| OTP 安全/风控记录 | 180 天 | 删除或聚合匿名化 |
| 活跃账号资料与训练记录 | 服务期间 | 注销后按下述流程擦除/匿名化 |
| 打卡照片 | 用户删除或账号注销即进入删除队列 | 24 小时内在线不可访问，备份最长 30 天自然轮转 |
| 推送 token | 最近活跃后 90 天或登出/注销 | 删除/失效 |
| 安全审计日志 | 180 天 | 分区删除；重大事件按法律要求保留 |
| 应用日志 | 30 天热存、最多 90 天归档 | 自动删除 |
| 数据库备份 | 30 天 | 加密轮转删除 |
| 匿名聚合指标 | 可长期 | 必须经重识别风险评估 |

这些期限均为 **provisional**：法务、监管、合同、争议处理需求或实际恢复演练改变时重评；任何延长须记录目的、范围和批准人。

注销执行：撤销会话和 token → 停止通知 → 解除教练关系 → 删除媒体对象/CDN 缓存 → 删除或不可逆匿名化业务行 → 更新搜索/读模型 → 生成内部完成证据。备份不做原地编辑，但恢复流程必须重新应用删除墓碑。

## 5. 应用安全控制

### 5.1 身份与滥用防护

- OTP 随机性使用密码学安全 RNG；只存带 pepper 的哈希；单次使用。
- 按手机号、IP、设备指纹、ASN/地域异常组合限流；统一响应避免账号枚举。
- 管理员和高权限教练 **provisional** 要求 MFA；若首发无法接入，至少敏感操作二次 OTP、IP/设备异常阻断。重评：S8 安全评审或出现接管事件时升级为上线门禁。
- 管理后台不对公网裸露管理接口；WAF、强认证、最小权限和会话锁定。

### 5.2 媒体安全

- 桶默认私有，禁止目录列举和永久公共 URL；上传/读取签名最短有效。
- 同时校验扩展名、MIME、文件魔数与实际解码结果；限制像素、文件大小和解压比，防图片炸弹。
- 服务端重新编码并移除 EXIF/GPS；原始隔离对象在处理完成后删除。
- 自动化内容安全结果 `suspect` 时仅本人可见并进入人工队列；未经合同与告知不得将照片发送到第三方模型。
- 教练每次读取照片校验活跃关系与照片同意，并记录资源、时间、目的；截图风险以水印与制度降低但不宣称彻底防止。

### 5.3 基础设施与研发

- TLS 1.2+；数据库、Redis、对象存储静态加密；L4 字段使用 KMS 信封加密。
- 生产密钥只在密钥管理/secret manager；仓库、CI 日志、客户端包不得含服务端密钥。
- 依赖锁定，CI 执行 SAST、secret scan、依赖漏洞与许可证检查；严重/高危漏洞不得带入生产，例外需负责人和到期日。
- 主分支保护、至少一人评审；涉及鉴权、支付（未来）、隐私删除和数据库迁移需双人评审。
- 每季度权限复核，人员离职当日撤权；生产 break-glass 账号每次使用告警并复盘。

## 6. 威胁场景与控制

| 场景 | 预防/检测/响应 |
|---|---|
| 短信轰炸与刷量 | 多维限流、风险挑战、日预算熔断、供应商账单告警 |
| 账号接管 | token 轮换复用检测、设备会话、异常登录、敏感操作二次验证 |
| 越权查看学员/照片 | ABAC、不可猜 ID、签名 URL、集成测试、照片访问审计 |
| 恶意图片/RCE | 直传隔离、魔数/像素校验、沙箱转码、worker 最小权限 |
| 批量爬取教练数据 | cursor 上限、速率限制、导出审批/水印、异常访问告警 |
| 日志泄露 | allowlist 结构化日志、SDK scrub、采样检查、短留存 |
| 供应链攻击 | lockfile、SBOM、签名构建、依赖扫描、受保护发布凭据 |
| 内部滥用 | 最小权限、字段遮蔽、理由码、不可变审计与定期抽查 |

## 7. 安全事件响应

- 严重级别：SEV-1（大规模泄露/完全不可用）、SEV-2（局部敏感暴露/核心功能显著退化）、SEV-3（低影响）。
- SEV-1：5 分钟告警，15 分钟确认指挥，先隔离凭据/通道并保全证据；1 小时内管理层与法务参与。
- 事件记录时间线、影响数据/主体、根因、缓解、通知判断和永久修复；通知监管/个人的义务和时间由法务依据事件确认。
- 每半年桌面演练：对象存储误公开、refresh token 泄露；上线前至少完成一次。

## 8. 上线安全门禁

- [ ] 无公开存储桶，无长期媒体 URL，无默认管理员密码。
- [ ] 会员 A、教练 A、教练 B 的横向/纵向越权自动化测试通过。
- [ ] OTP 枚举、重放、频控和预算熔断测试通过。
- [ ] 删除后 CDN、对象存储、读模型不可访问；备份恢复能重新应用删除。
- [ ] 移动端抓包确认无敏感日志、无明文 token、无未披露 SDK 上报。
- [ ] 渗透测试高危/严重问题清零；中危具备修复期限和风险接受人。
- [ ] 隐私政策、单独同意、SDK 清单、备案、等保结论均有责任人签字。
