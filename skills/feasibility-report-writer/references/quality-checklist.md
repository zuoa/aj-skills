# 质量校验清单（Stage 4）

组装完整报告后，逐项过五道门。全部通过方可交付；未过项写入工作目录下的 `outputs/quality_report.json` 并标红提示。

## 门 1 — 真实性门

- [ ] 无把「合理推断」「建议方案」「未检索结果」写成事实；
- [ ] 关键数据/政策/现状均有信源，**正文不出现 `[信源N]`**，信源集中在独立清单；
- [ ] 量化效益/指标有测算依据或已改定性 + `【待验证：…】`；
- [ ] 无杜撰文号、数据、作者、机构、链接。

## 门 2 — 字数门（`{baseDir}/scripts/wordcount_check.py`，`--report` 写工作目录的 `outputs/quality_report.json`）

- [ ] 第一章 ≤ 800；
- [ ] 第二章 ≤ 500；
- [ ] 第三章 ≤ 1000；
- [ ] 第四章 ≤ 1000；
- [ ] 第五章 ≤ 2000；
- [ ] 第六章 ≤ 1000。

统计口径：按章统计中文字符 + 阿拉伯数字，剔除 markdown 标记、标点、空白。超限章节先压缩口号/重复，不删数据与信源。

## 门 3 — 一致性门

- [ ] 第一章研究内容 = 第四章关键技术 = 第五章技术路线（同一套方案）；
- [ ] 第四章每条关键技术都点名了**具体核心技术**（算法/模型/方法），有机理 + 可考核指标，无「智能/先进」空话替代；
- [ ] 第五章技术路线含**分层架构 + 逐模块技术路径（输入→算法→输出→衔接）+ 数据流**；图 1 是技术架构/数据流图（**非时间轴/甘特**）；未把阶段流水账写进技术路线；
- [ ] 第五章（一）实施方案含**建设内容分解（建什么/交付物）+ 技术/平台硬件 + 数据方案 + 试验验证设计**，点名了具体技术栈/硬件，非泛泛而谈；
- [ ] 第五章进度成果指标（专利/论文/软著/示范数）= 第六章预期目标数字；
- [ ] 第三章团队节奏 ↔ 第五章进度周期 ↔ 第一章研究起止一致；
- [ ] 全文术语、单位、数据同名同义；图号连续，正文图元与图中一致。

## 门 4 — 引用门（正文无标记 · 信源清单完整）

- [ ] 正文无任何 `[信源N]` 标记（`{baseDir}/scripts/generate_docx.py` 的 `citation_audit` 应 `body_clean=true`）；
- [ ] 信源清单每条都有标题、链接，且标注「用于哪章·引用了什么」（无空 `used_in`）；
- [ ] `sources.json` 与 `参考文献与信源清单.md` 序号与条目一致；
- [ ] 链接可达性抽查通过；失效链接标红；
- [ ] 无网络检索时，清单已显式标注「未执行外部检索」。

## 门 5 — 格式门（严格对齐 `report-template.md`「格式规范」，由 `generate_docx.py` 自动套用）

- [ ] 封面：项目名称（小一 24/黑体/居中）、副标题「项目可行性报告」、承担单位与申报年月（四号 14/宋体加粗/居中）齐全；
- [ ] 章标题 `一、…` 三号 16 黑体顶格；节标题 `（一）…` 小三 15 宋体**加粗**、首行缩进2字符；正文/条 小三 15 宋体、首行缩进2字符、两端对齐；
- [ ] 图题 `图 1 …` 四号 14 居中，图在图题上方居中；
- [ ] 页眉「…可行性分析报告」+ 页脚「第 X 页」已注入；封面（首页）无页眉页脚；
- [ ] `【待确认：…】`/`【待验证：…】` 在 Word 中显示为**蓝色斜体**（评审可一眼定位待办）；
- [ ] 技术路线图（图 1）已嵌入，图号、图题正确；
- [ ] 无遗留 `【待确认：…】` 影响关键判断（或已显式列入交付说明）。

## quality_report.json 格式

```json
{
  "checked_at": "由调用方注入时间戳",
  "wordcount": {"一": {"actual": 780, "limit": 800, "pass": true}, "...": {}},
  "gates": {
    "真实性门": "pass",
    "字数门": "pass",
    "一致性门": "warn: 第五章成果指标与第六章专利数不一致",
    "引用门": "pass",
    "格式门": "pass"
  },
  "orphan_sources": [],
  "missing_sources": [],
  "broken_links": []
}
```

未通过的项不得静默放过：要么修正，要么在交付说明里显式列出，由用户决定是否接受。
