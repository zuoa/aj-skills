# 分章撰写指南

配合 `report-template.md` 使用。每一章给出：写作要点、常见坑、字数策略、1 段匿名范例（取自真实公益类科技项目可研，仅示结构与海拔，不抄领域内容）。

通用纪律：术语首次出现定义，全文同名同义；量化必有依据，否则改定性 + `【待验证：…】`；外部引用一律记入独立信源清单，**正文不出现 `[信源N]` 标记**。

---

## 第一章　背景与意义（≤800）

**要点**：用数据 + 政策两条线论证「这件事值得做、现在该做」，自然引出研究内容。三段式：产业现状 → 政策依据 → 现存问题 → 研究内容。

**常见坑**：
- 堆砌「意义重大、前景广阔」而无数据；
- 政策文件只写名字不写文号/发布机构，或杜撰文号；
- 现存问题与研究内容脱节（问题写一堆，研究内容没对应解决）。

**字数策略**：背景 250 / 政策 150 / 问题 200 / 研究内容 200。超限时先压缩口号与重复表述，不删数据。

**范例片段**：
> [研究对象]是我省[规模]万亩、年产量约[N]万吨、产值超[N]亿元的特色产业。国家《[规划名]》提出加快[技术]在农业生产中的集成应用，为本项目提供政策支撑。[区域]生产前期长期处于低温高湿环境，[病害]易发生流行，仅靠人工经验难以及时诊断。现有智能装备主要面向大型标准化温室，缺少适配[本地设施]的智能巡检装备。针对上述问题，本项目拟研发[核心装备]，构建「自动巡检—智能感知—智能诊断—环境调控—绿色防控」一体化技术模式。（规模/产值/政策信源记入独立信源清单。）

## 第二章　国内外研究现状（≤500）

**要点**：国外 → 国内 → 趋势三段。每段必须有信源（期刊/权威机构），近 3–5 年为主。结尾点明本项目切入点。

**常见坑**：
- 现状写成教科书常识，无具体团队/成果/时间；
- 国内外只写「取得了较大进展」类空话；
- 把模型记忆当信源，无链接/出处。

**字数策略**：国外 180 / 国内 200 / 趋势 120。无网络检索时显式标注「未执行外部检索」，只写可溯源已知事实。

**范例片段**：
> （一）国外：[国家/机构]在[方向]已实现[能力]，代表性进展为……。（二）国内：[团队]在[方向]取得[成果]，但仍存在[不足]。（三）发展趋势：未来[方向]将向[趋势]演进，本项目在[切入点]上具备[优势]。（国内外现状信源记入独立信源清单。）

## 第三章　现有工作基础与条件（≤1000）

**要点**：单位条件 → 负责人 → 团队 → 技术储备 → 合作单位（→ 企业牵头财务）。证明「我们做得起、做得成」。

**常见坑**：
- 设备/论文只列名称不给数量与水平；
- 负责人成果与本项目方向无关，硬凑；
- 漏写合作单位分工，或企业牵头漏财务指标。

**字数策略**：单位 250 / 负责人 250 / 团队 200 / 技术储备 150 / 合作 150。负责人论文用「第一/通讯作者 [N] 篇，其中 SCI [n] 篇」量化。

**范例片段**：
> [单位]为公益一类事业单位，内设[N]个研究所，拥有[重点实验室]及[关键设备列举]，可保障项目实施。项目负责人[姓名]，[学位]，从事[方向]，曾主持[代表项目]，以第一作者发表论文[N]篇（SCI [n] 篇），具组织协调能力。团队含[专业领域]人员，围绕[领域]发表论文[N]篇。【待确认：负责人近 3 年项目与论文清单、合作单位全称与分工】

## 第四章　关键技术与创新（≤1000）

**要点**：(一)关键技术必须**点名到具体算法/模型/方法**，按「难点 → 核心方法与机理 → 实现要点 → 量化指标」分条；只写「用 AI / 智能 / 先进」一类空话 = 不合格。(二)创新按「主张 → 与现有区别 → 机理 → 意义」分条。关键技术 ↔ 创新点 ↔ 第五章技术路线模块 三者 1:1 呼应。

**常见坑**：
- **关键技术不点名核心技术**：只写「智能识别 / 先进算法」，不说具体是 YOLOv8、迁移学习、多源融合还是轻量化推理；
- 用「智能/先进/高效/强大」替代可归因的技术机理；
- 关键技术写成研究内容或进度的复述，没有「怎么实现」；
- 创新点与关键技术重复或脱节；量化效果无依据却写成确定数字。

**字数策略**：关键技术 500 / 创新 500，各 2–3 条。关键技术每条先把「具体技术名」亮出来，再给机理（模型结构/融合策略/训练方式）与可考核指标。

**深度自检**：每条关键技术能否回答——①具体用了什么算法/模型/方法（可检索）？②为什么用它而非现成方案？③靠什么数据、怎么训练/工程化？④达到什么可考核指标？四问有一答不上，就是太浅。

**范例片段**（仅示深度与结构，不抄领域内容）：
> （一）关键技术：1、[病害早期识别——基于 ResNet50+迁移学习]。难点：[发病初期症状与缺水等生理胁迫肉眼难辨，且标注样本少]。方法：以 [ImageNet 预训练 ResNet50] 为骨干，[冻结浅层+微调深层]，引入 [温湿度等环境因子作辅助通道] 融合，输出 [病害概率+置信度]。实现：[采集 X 张田间图像，数据增广扩样，按 8:2 划分；取置信度 0.6 为阈值]。指标：[识别准确率≥90%、误报率≤8%]（依据：同类公开数据集基线，或 `【待验证：…】`）。2、[多源数据融合——视觉+RFID+环境传感器的时间对齐与特征级融合]……（二）创新：1、[多模态融合的早期识别方法]。区别于 [单一图像识别]，通过 [视觉特征×环境时序×个体ID 的特征级融合]，突破 [单一传感器在早期/低样本下失效] 的局限……

## 第五章　实施方案·技术路线·进度（≤2000）

**要点**：四小节。(一)实施方案：**建设内容分解（建什么/交付物）+ 技术与平台硬件（用什么）+ 数据方案 + 实施步骤 + 试验验证设计**（怎么开展/怎么验证），不泛泛而谈；(二)技术路线：**分层技术架构 + 逐模块技术路径（输入→算法→输出→衔接）+ 数据流 + 图 1**，讲技术上的「怎么做」；(三)组织方式（产学研用分工+管理组）；(四)进度表（起止年月+工作计划+阶段目标，含成果指标）。

**常见坑**：
- **实施方案泛泛而谈**：只写「采用先进技术、分四阶段实施」，不点名具体建设对象、技术栈/硬件、数据方案与验证设计；
- **技术路线写成阶段流水账**：把「基础研究—系统开发—集成应用—示范推广」塞进技术路线（那是实施方案/进度），导致技术路线空泛；
- **图 1 画成时间轴/甘特图**：技术路线图必须是分层架构或数据流图，不是进度时间线；
- **不写逐模块技术路径**：只说「采用 AI 建模」，不说每个模块输入什么、跑什么模型、输出什么、怎么衔接；
- 技术路线与第四章关键技术不对应、术语不一致、图号不连续；
- 进度起止与第一章研究周期、成果指标与第六章预期目标矛盾；阶段目标只有「完成开发」无量化成果。

**字数策略**：方案 500 / 路线 500 / 组织 300 / 进度 700。进度表用表格省字数。技术路线图优先程序化生成（matplotlib/mermaid，**分层模块 + 数据流向连线**），失败保留源文件与错误，不伪称已生成。

**深度自检（实施方案）**：能否回答——①具体要建几个什么对象（系统/平台/装备/模型），各交付物是什么？②用什么技术栈、开发框架、硬件平台（可点名）？③数据从哪来、多少、怎么标注质控？④在哪验证、怎么设对照、按什么指标判定？答不上就是泛泛而谈。

**深度自检（技术路线）**：能否回答——①系统分几层、每层有哪些模块？②每个关键模块输入什么数据、跑哪个具体模型/算法、输出什么？③数据从采集到反馈怎么流？④图 1 是架构/数据流图（不是时间轴）且与正文术语一致？

**范例片段**（仅示深度与结构，不抄领域内容）：
> （一）实施方案：建设内容包括 ①[智能巡检装备样机 1 套（吊轨式，含相机/传感器/边缘节点）]；②[病害与生育期识别模型 2 个]；③[协同防控平台 1 套]。技术上采用 [PyTorch+YOLOv8 训练、Flask 平台]，硬件侧 [吊轨+RGB/多光谱相机+温湿度传感器+Jetson 边缘节点+LoRa 通信]、[边端推理+云端管理] 部署；数据 [在 N 个试验棚采集图像 X 万张+环境序列，专人标注+双人复核]。实施按 需求→设计→开发→集成→测试→部署→示范 推进。验证依托 [N 个示范基地]，设 [常规人工棚为对照]，按 [识别准确率、亩均增产、农药减施比例] 考核。
> （二）技术路线：系统按「感知层—算法层—平台层」组织（图 1）。感知层以 [摄像头+温湿度传感器] 采集 [图像与环境序列]，经 [边缘端预处理/去畸变] 送算法层；算法层由 [模型A：YOLOv8 病害检测] 输出 [病斑位置与等级]、[模型B：LSTM 生育期识别] 输出 [生育阶段]，二者结果与 [环境数据] 在平台层 [规则引擎] 融合做 [调控决策]，再由 [补光/通风/施药执行机构] 闭环。数据流：采集→边缘预处理→模型推理→平台决策→执行反馈→回采。选型理由：[边缘推理保证实时性，迁移学习应对小样本]。图 1 研究技术路线图（分层架构+数据流）。

## 第六章　预期目标（≤1000）

**要点**：(一)技术指标（知识产权/标准/新装置/论文+竞争分析）；(二)经济·社会·生态效益；(三)人才培养。技术指标须与第五章进度成果一一对应。

**常见坑**：
- 效益数字无测算依据（如「增收 30%」无基线）；
- 技术指标（专利数）与第五章进度不一致；
- 经济/社会/生态混写。

**字数策略**：技术指标 350 / 效益 500 / 人才 150。效益量化须附测算依据或改定性。

**范例片段**：
> （一）技术指标：申请专利[N]项、软著[N]项，发表论文[N]篇（SCI [n]篇），形成[新装置/新方法]，与国内外同类相比[优势]。（二）效益：经济——预计[亩均增收/降本]，【测算依据：…】；社会——带动农户[N]户；生态——[绿色防控/减排]。（三）培养研究生[N]名、骨干[N]名。

## 跨章一致性自检（撰写时随时对照）

- 第一章研究内容 ↔ 第四章关键技术 ↔ 第五章技术路线，三者描述同一套方案；
- 第五章进度成果指标（专利/论文/示范数）= 第六章预期目标数字；
- 第三章团队节奏 ↔ 第五章进度周期；
- 全文术语、单位、数据一致；信源全部在独立清单内且每条标注「用于哪章·引用了什么」，正文不出现 `[信源N]`。
